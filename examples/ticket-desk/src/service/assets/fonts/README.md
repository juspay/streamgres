# Typography

Unmodified Latin webfont files from https://xyne.ai/streamgres, retrieved
13 November 2026. They are embedded in the demo binary and served locally.

- Google Sans Flex: headings, SIL Open Font License.
- Manrope: body and controls, SIL Open Font License.
- Geist Mono: labels and measurements, SIL Open Font License.

Upstream license texts are included individually and in LICENSES.txt, which
the binary also serves at /fonts/licenses.txt. Provenance and font asset URLs
are recorded in the example README.
